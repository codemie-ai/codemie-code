# Shell Completions Implementation Plan (EPMCDME-17673)

> For agentic workers: use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax. This run delivers the plan only; implementation is a later stage.

**Goal:** `codemie completion <bash|zsh|fish>` prints a static completion script generated from the live commander tree.
**Architecture:** `src/cli/completion/` holds a tree model (`tree.ts`), one pure emitter per shell, and a registry (`index.ts`). The command walks `createProgram()` via the parent chain (as `tips.ts` `rootOf`). Startup silencing goes through `getInvocationContext` only.
**Tech Stack:** TypeScript ESM (`.js` imports, `@/` alias), commander 11.1, vitest.
**Spec:** `docs/superpowers/tasks/2026-11-24-shell-completions-plan/spec.md`

Commit per task using the repository's existing convention (Conventional Commits, ticket per `.ai-run/guides/standards/git-workflow.md`).

## Global Constraints
- Bash output must run on 3.2: no `mapfile`, `readarray`, `declare -A`, or bash-completion dependency.
- Output is the script only on stdout, written in one `process.stdout.write`; errors on stderr, exit 1.
- Root name comes from `model.name`, never a literal. Each script has a header comment `# codemie completion <shell> — generated by codemie vX.Y.Z` (version from package.json).
- Option value rule, same in all shells: offer `choices` if present; otherwise files only when `valueKind` is `path`; otherwise nothing.
- Non-goals: PowerShell, plain sh, dynamic values, `--opt=value`, per-agent binaries, rc auto-install, changes to `src/cli/index.ts` routing.

## Review Focus
- Description containing newline and `$(touch SENTINEL)`: script stays valid and runs nothing (Task 3).
- Hidden command/option (including after commander bump): never offered (Tasks 1, 8).
- `codemie list --<Tab>` vs root options accepted after a subcommand (Task 2).
- Stdout purity with pending migration, update check on, `CODEMIE_DEBUG=true` (Task 7).
- Missing zsh/fish in CI must fail, not skip (Tasks 5, 6, 9).

## Acceptance of "forward-looking" paths
Alias handling has no real data in the CLI today; it is tested on synthetic trees only.
